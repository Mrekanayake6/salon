# Maison Belle — Premium Salon & Beauty Studio

Static frontend built with HTML5, CSS3, Bootstrap 5, Bootstrap Icons, and Vanilla JavaScript.

Open `index.html` directly in a browser or serve the folder with a local web server.

## Pages
- index.html
- services.html
- service-details.html
- about.html
- team.html
- gallery.html
- offers.html
- booking.html
- contact.html
- login.html
- register.html
- my-bookings.html

## Assets
Remote Unsplash images are used as demo imagery. Replace them with local files in `assets/images/` when branding is ready.

## Demo booking
Booking state is stored in `localStorage` so the flow works without a backend. The structure is intentionally easy to replace with a real API later.
